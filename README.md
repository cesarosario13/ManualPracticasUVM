## Descripción del Proyecto
Este repositorio contiene un manual colaborativo diseñado para establecer estándares de calidad, organización y trabajo en equipo en la elaboración de proyectos universitarios, siendo gestionado completamente utilizando metodologías ágiles, control de versiones mediante la plataforma GitHub y revisión por pares (Pull Requests).

///

## Instrucciones de Uso

Si deseas acceder al contenido de este manual, tienes dos opciones:

**Opción 1: Descargar la versión final (Recomendado para lectura)**
1. Dirígete a la sección **Releases** en la barra lateral derecha de este repositorio.
2. Haz clic en la última versión estable (`v1.0`).
3. Descarga el archivo PDF adjunto para leer el manual con el formato final aplicado.

**Opción 2: Clonar el repositorio localmente (Para estudiantes y desarrolladores)**
Si deseas tener los archivos fuente en formato Markdown, ejecuta el siguiente comando en tu consola:

git clone [https://github.com/cesarosario13/ManualPracticasUVM.git]
