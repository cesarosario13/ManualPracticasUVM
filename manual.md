# Manual Rápido de Buenas Prácticas para Trabajos Universitarios en Grupo

Integrantes: Cesar Rosario y Gustavo Avendaño  

///

## 1. Cómo nos organizamos (Tiempo)
* **Reuniones:** Nos pondremos de acuerdo por Whatsapp para definir que hace cada uno.
* **Entregas:** Iremos subiendo los avances a GitHub cada vez que terminemos un tema y no se entregara hasta que ambos hayamos revisado el documento final.

## 2. Formato de los documentos (Normas)
* **Letra y tamaño:** Usaremos Arial 11.
* **Márgenes:** Normales (2.54 cm por lado, al estilo APA).
* **Citas:** Si se copia algo de internet, se pondrá el enlace o el autor al final en la Bibliografía.

## 3. Herramientas que usamos
* **Para escribir documentos:** Word.
* **Para guardar las versiones finales:** Git y GitHub.
* **Para comunicarnos:** Whatsapp y Telegram.
